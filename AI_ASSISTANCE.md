# AI Assistance

This project was developed with AI-assisted implementation, test generation, and documentation under human-directed product scope.

Human responsibility remains with contract selection, public/private boundary decisions, security review, acceptance criteria, release approval, and interpretation of benchmark results. AI output is not treated as evidence by itself; tests, counter-proofs, report hashes, and CI provide the reproducible evidence.

No private corpus, client data, secret, production topology, or code from a private repository was copied into this project. All examples are synthetic.
